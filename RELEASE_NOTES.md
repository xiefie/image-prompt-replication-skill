# v1.0.0 — Initial release

## English

The first public release of Image Prompt Replication Skill turns reference-image prompting into a controlled three-mode workflow:

- reverse-engineer a reference into a structured English generation prompt;
- compare an original and generated result, then revise only the highest-impact causes;
- extract reusable visual style without carrying over scene content.

The release also includes bilingual usage and design documentation, dependency-free validation, GitHub Actions, issue/PR templates, and an installable ZIP bundle.

The skill aims for high perceptual similarity but does not claim that text alone can guarantee pixel-identical results.

## 中文

Image Prompt Replication Skill 的首个公开版本将参考图提示词工作整理为三种可控模式：

- 从参考图反推结构化英文生图提示词；
- 对比原图与生成结果，只修改影响最大的差异原因；
- 提取可复用视觉风格，同时排除场景与主体内容。

本版本同时包含中英文使用与设计说明、无第三方依赖的校验脚本、GitHub Actions、Issue/PR 模板和可直接安装的 ZIP 压缩包。
