# Security policy

## Supported versions

Security fixes are applied to the latest release.

## Reporting a vulnerability

Please do not publish exploitable prompt-injection, malicious archive, or supply-chain details in a public issue.

Use GitHub's private vulnerability reporting or Security Advisories feature for this repository. Include:

- the affected file and version;
- a minimal reproduction;
- the expected and observed behavior;
- the potential impact;
- a suggested mitigation, if available.

This repository contains prompt instructions and validation tooling. It does not require credentials, execute downloaded code, or make network requests at runtime. Treat unexpected changes that add such behavior as security-sensitive.
